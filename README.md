A one-line deadpan weather forecast for an invented city, written by `main.py` to `/output/entry.txt`.

Run it with:

```bash
python3 main.py
```

The program uses only the Python standard library, creates `/output` if needed, writes the forecast as UTF-8 text, and exits with code 0.
